Redis AI Research

Public projects and experiments built on Redis

This monorepo collects open-source work from the Redis AI Research team exploring semantic caching, vector search, retrieval-augmented generation, agentic systems, and evaluation workflows.

Repository: redis/redis-ai-research-public
